# Robot Math Adventure 3D

Game edukasi perkalian 1–10 untuk siswa SD, dengan robot 3D biru-kuning tanpa mulut dan mekanisme memilih gerbang jawaban pada lintasan tiga jalur.

## Dokumen proyek
- `PRD.md` — kebutuhan dan aturan produk.
- `DEVELOPMENT_PLAN.md` — arsitektur dan tahapan implementasi.
- `TEST_PLAN.md` — skenario pengujian dan kriteria rilis.

## Spesifikasi ringkas
- 5 level.
- 10 soal per level.
- 3 opsi per soal, tepat 1 benar.
- Perkalian dengan faktor 1–10.
- Skor jawaban benar: +100.
- Nyawa awal: 3 per level.
- Platform: browser desktop dan mobile.
- Hosting target: GitHub Pages.

## Status
Dokumen ini adalah spesifikasi perencanaan. Kode game belum termasuk dalam paket dokumen ini.
